# RunSMS 使用指南

[RunSMS 官网](https://runsms.com/zh) · [X（Twitter） @runsmscom](https://x.com/runsmscom) · [联系 RunSMS](https://runsms.com/zh/contact)

RunSMS 提供临时号码和租赁号码，用于接收受支持的账户短信。这里整理号码选型、使用前检查和官方服务入口。

## 选择号码

| 你的需求 | 对应入口 |
| --- | --- |
| 只需要接收一次账户短信 | [临时号码服务目录](https://runsms.com/zh/services) |
| 需要在选定周期内继续使用同一个号码 | [租赁号码和套餐](https://runsms.com/zh/rental-services) |
| 想体验公开短信收件箱 | [免费接码](https://runsms.com/zh/free-sms) |

免费接码的收件箱公开可见。请勿用公开号码接收私人信息，也不要将公开号码用作重要账户的找回方式。

## 使用前检查

1. 在目标应用的官方页面确认当前操作需要短信验证，并查看是否对号码地区或类型有限制。
2. 在对应目录中搜索应用名称，核对服务、当前价格和使用规则。找不到应用时，可参考[目录搜索和下单检查指南](https://runsms.com/zh/blog/sms-service-not-listed-checklist)。
3. 如果账户以后还要用同一个号码验证，先确认需要保留多久，并设置你能持续使用的账户找回方式。
